
# GM7 — Community Platform

A digital platform built to bring the GM7 community together, creating a modern and engaging online experience.

## About the Project

GM7 is a community-focused website designed to connect members, encourage interaction, and provide a central space for the community.

The project is directed by **Dexter** and designed and developed by **Emberlyn Team**, with a focus on creativity, performance, and modern web experiences.
